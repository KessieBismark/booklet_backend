# booklet

A production-ready **FastAPI** backend (GraphQL + REST, asynchronous) generated from your database schema — SQLAlchemy models, Pydantic schemas, routers/resolvers, JWT auth, filtering, sorting, pagination, Alembic migrations and Docker, all included.

## Quick start

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# point DATABASE_URL at your database (see config/dbconfig.py)
python main.py            # or: uvicorn main:app --reload
```

On startup the app opens a **documentation portal** at `/portal` in your browser (disable with `OPEN_BROWSER=0`).
