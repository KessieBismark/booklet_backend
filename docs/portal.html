Authentication

All data endpoints require a JWT bearer token:

Authorization: Bearer <your-token>

Auth models (those with email/username + password) expose the token flow: register → login (returns an access token + a refresh token) → call endpoints with the access token → refresh when it expires → change‑password. Each auth model's exact REST routes and GraphQL mutations are listed in its section below.

ParamTypeDescription

GraphQL

Each model exposes <model>_list, <model>_by_id, <model>_count, <model>_aggregation queries and create_/update_/delete_ mutations. _list accepts filter_group (AND/OR groups of {field, operator, value}), order_by, pagination, search and after.
